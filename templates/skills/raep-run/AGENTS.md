## Available agents

### planner
Plans project phases, requirements, and roadmap. Use for new features and project planning.

### architect
System design, architecture decisions, and technical roadmaps. Use for architectural questions.

### tdd-guide
Test-driven development guidance. Use when writing tests or doing TDD cycles.

### code-reviewer
Code quality review. Use for PR reviews and quality gates.

### security-reviewer
Security analysis and vulnerability detection. Use for auth, payments, and sensitive features.

### build-error-resolver
Diagnoses and resolves build errors, compilation failures, and CI issues.

### doc-updater
Keeps documentation in sync with code changes.

### e2e-runner
End-to-end test orchestration with Playwright/Cypress.

### refactor-cleaner
Code refactoring, cleanup, and technical debt reduction.

### database-reviewer
Database schema review, query optimization, and migration safety.

## Delegation rules

- For new features: start with **planner** → **architect** → **tdd-guide**
- For bug fixes: start with **build-error-resolver** → **code-reviewer**
- For security concerns: always involve **security-reviewer**
- For database changes: always involve **database-reviewer**
- For documentation: delegate to **doc-updater** after code changes
- For end-to-end tests: delegate to **e2e-runner**
